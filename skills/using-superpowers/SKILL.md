ถ้าคุณถูกส่งมาเป็น subagent เพื่อทำงานเฉพาะอย่าง ให้ข้าม skill นี้
</SUBAGENT-STOP>

<EXTREMELY-IMPORTANT>
ถ้าคิดว่ามีโอกาสแม้ 1% ที่ skill ใดจะเกี่ยวข้องกับสิ่งที่กำลังทำ คุณต้องเรียก skill นั้นโดยไม่มีข้อยกเว้น

ถ้ามี skill ที่ตรงกับงาน คุณไม่มีทางเลือก ต้องใช้

เรื่องนี้ต่อรองไม่ได้ และห้ามหาเหตุผลมาเลี่ยง
</EXTREMELY-IMPORTANT>

## กฎ

**เรียก skill ที่เกี่ยวข้องหรือที่ถูกขอ "ก่อน" ตอบหรือลงมือทำอะไร** รวมถึงก่อนถามคำถามเพื่อขอความชัดเจน ก่อนสำรวจโค้ด หรือก่อนเปิดไฟล์ ถ้าเรียกแล้วพบว่าไม่เหมาะกับสถานการณ์ ก็ไม่ต้องใช้ต่อ

**ก่อนเข้า plan mode:** ถ้ายังไม่ได้ brainstorm ให้เรียก skill brainstorming ก่อน

จากนั้นประกาศว่า "ใช้ [skill] เพื่อ [วัตถุประสงค์]" แล้วทำตาม skill อย่างตรงตัว ถ้ามี checklist ให้สร้าง todo หนึ่งรายการต่อหนึ่งข้อ

## ลำดับความสำคัญของ skill

เมื่อมีหลาย skill ที่เกี่ยวข้อง ให้ใช้ skill ด้านกระบวนการก่อน เพราะมันกำหนดแนวทาง แล้วค่อยใช้ skill ด้านการลงมือ (frontend-design ฯลฯ) brainstorming และ systematic-debugging เป็น skill ด้านกระบวนการที่พบบ่อยที่สุดของ Superpowers แต่กฎนี้ใช้กับ skill กระบวนการทุกตัว

- "มาสร้าง X กัน" → super-ripple:brainstorming ก่อน แล้วค่อย skill ด้านการลงมือ
- "แก้บั๊กนี้" → super-ripple:systematic-debugging ก่อน แล้วค่อย skill เฉพาะด้าน
- สร้างระบบซอฟต์แวร์ตั้งแต่ต้น → super-ripple:brainstorming (ได้ spec) → super-ripple:design (ได้ design) → super-ripple:writing-plans (ได้แผน) → ลงมือ ทุกขั้นเริ่มกลางทางได้ถ้ามีอินพุตของมัน ไม่ต้องย้อนไปขั้นก่อน

## สัญญาณเตือน

ถ้าคิดแบบนี้ แปลว่ากำลังหาเหตุผลเลี่ยง ให้หยุด:

| ความคิด | ความจริง |
|---------|---------|
| "นี่แค่คำถามง่ายๆ" | คำถามก็คืองาน ให้ตรวจหา skill |
| "ขอข้อมูลเพิ่มก่อน" | ตรวจ skill ก่อนถามเพื่อขอความชัดเจน |
| "ขอสำรวจโค้ดก่อน" | skill บอกว่าควรสำรวจอย่างไร ตรวจก่อน |
| "เช็ก git/ไฟล์แป๊บเดียว" | ไฟล์ไม่มีบริบทของบทสนทนา ให้ตรวจหา skill |
| "ขอรวบรวมข้อมูลก่อน" | skill บอกวิธีรวบรวมข้อมูล |
| "งานนี้ไม่ต้องใช้ skill จริงจัง" | ถ้ามี skill อยู่ ก็ใช้ |
| "จำ skill นี้ได้อยู่" | skill เปลี่ยนไปได้ ให้อ่านฉบับปัจจุบัน |
| "นี่ไม่นับเป็นงาน" | การลงมือทำคืองาน ให้ตรวจหา skill |
| "skill นี้เกินความจำเป็น" | เรื่องง่ายกลายเป็นเรื่องยากได้ ใช้มัน |
| "ขอทำอย่างนี้ก่อนอย่างเดียว" | ตรวจก่อนทำอะไรทั้งนั้น |
| "แบบนี้รู้สึกว่าคืบหน้า" | การลงมือแบบไร้วินัยเสียเวลา skill ป้องกันเรื่องนี้ |
| "รู้อยู่แล้วว่าหมายถึงอะไร" | รู้แนวคิด ≠ ใช้ skill เรียกมันซะ |
